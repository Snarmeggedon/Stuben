### Bug #2: Unhandled PermissionError in Directory Iteration ✅

**Severity:** MEDIUM  
**Component:** `analyzer.py` (lines 116-127 in `analyze_directory()`)  
**Issue:** Protected directories like `$RECYCLE.BIN` caused uncaught `PermissionError` exceptions

**Before (Broken):**
```python
def analyze_directory(self, directory, recursive=True):
    path = Path(directory)
    if not path.exists():
        return self._build_missing_result(path, 'directory')

    findings = []
    for item in sorted(path.iterdir()):  # ← Throws PermissionError on protected dirs
        if item.is_dir() and recursive:
            findings.extend(self.analyze_directory(item, recursive=True))
        elif item.is_file() and item.suffix.lower() in self.SCANNABLE_SUFFIXES:
            findings.extend(self.analyze_file(str(item)))
    return findings
```

**Error Message:**
```
ERROR
[WinError 5] Access is denied: 'C:\\$RECYCLE.BIN\\S-1-5-18'
```

**After (Fixed):**
```python
def analyze_directory(self, directory, recursive=True):
    path = Path(directory)
    if not path.exists():
        return self._build_missing_result(path, 'directory')

    findings = []
    try:
        items = sorted(path.iterdir())
    except PermissionError:
        return findings  # Gracefully skip protected directories
    except Exception:
        return findings  # Gracefully skip other errors
    
    for item in items:
        try:
            if item.is_dir() and recursive:
                findings.extend(self.analyze_directory(item, recursive=True))
            elif item.is_file() and item.suffix.lower() in self.SCANNABLE_SUFFIXES:
                findings.extend(self.analyze_file(str(item)))
        except PermissionError:
            continue  # Skip inaccessible files/dirs
        except Exception:
            continue  # Skip other errors
    return findings
```

**Root Cause:** 
- `Path.iterdir()` on protected directories throws `PermissionError`
- No try/except wrapped around directory iteration
- No try/except wrapped around individual file checks

**Verification:** 
- Protected directories like `$RECYCLE.BIN` now gracefully skipped
- Scanning continues without crashing
- No error messages for permission denied
